# WorldMind 스펙 요약

> 원본 `WorldMind-스펙.md`의 핵심 제약을 요약한 문서입니다. 원본 파일이 있으면 이 폴더에 함께 두세요.
> 본 프로젝트는 원본 스펙 §0~§10을 기준으로 재구축되었고, 이후 요청으로 기능이 추가되었습니다(맨 아래 "추가된 기능").

## §0 기본
- 단일 HTML(`site/index.html`), Vanilla JS, CDN은 Google Fonts(Cinzel·Noto Sans KR)와 Firebase compat 10.12.2만.
- 연결선은 SVG. 한국어 UI.

## §1 데이터 스키마 (변경 금지)
- `tabs[]` + `activeTabId`. Tab `{id, title, nodes, edges, events, worldPrompt, refImages(base64 최대 3, 로컬 전용)}`
- Node `{id, type, types[], props[{k,v}], links[{url,label}], memo, imgs[{id,w,h,cap}], name, desc, x, y, _exp(런타임), _aiPreview(런타임)}`
  · `types` = 노드가 겸하는 타입 key 목록. **맨 앞이 주 타입**이고 `type` 은 항상 `types[0]` 과 같게 유지한다(색·정렬·AI 프롬프트가 `type` 을 읽는다).
  · `props` = 구조화 속성(순서 보존). 값이 비어도 항목은 남는다 — 타입 템플릿 자리표시자이기 때문. 카드 요약에는 값이 채워진 것만 최대 4개.
- Edge `{id, from, to, label, desc, isParent}` (isParent: from=부모 → to=자식), Event `{id, time, body, order}`
- `gid()='i'+(idC++)`, `idC=Date.now()`. `sanitizeTab` 필수 통과.
- Tab `nodeTypes = [{key,label}]` — **탭별 노드 타입**. 배열 순서가 상하위 단계(맨 위=최상위)이고 색은 순서대로 자동 배정하며 이모지는 없다. 새 탭은 기본 7종(world…custom)으로 시작하고, 구 데이터에는 필드가 없으므로 `sanitizeTab` 이 기본 7종으로 채워 기존 `node.type` 과 그대로 맞는다. `key` 는 불변, `label` 만 변경한다.

## §2 저장소 (키·경로 변경 금지)
- localStorage `wm_tabs = JSON.stringify({tabs})`, `wm_fbcfg`(Firebase 설정 원문). (`wm_k/wm_gk/wm_mh`는 프록시 전환 후 미사용)
- Firebase `worldmind/tabList[{id,title}]`, `worldmind/tabs/{tabId}/{meta{title,worldPrompt,_w}, nodes/{id}{…,_w}, edges/{id}{…,_w}, events/{id}{…,_w}}`
- `_w` = 세션 ID `FB_SID='s'+Date.now().toString(36)+Math.random().toString(36).slice(2,6)` (자기 쓰기 에코 무시)
- §2-3 구 포맷 `worldmind/{tabs:[…]}`는 초기화 시 손실 없이 항목별 경로로 마이그레이션.

## §3 실시간 동기화
- 전체 덮어쓰기 금지, 변경 항목만 diff `set()`. `child_added/changed/removed` 리스너. `_w===FB_SID` 무시.
- 탭 전환 시 리스너 해제/재부착. tabList value 리스너. 원격 수신 50ms 디바운스 렌더.
- 상태 칩: 실시간 동기화 / 연결 중… / 연결 오류 / 오프라인.
- Firebase 설정 파서: 순수 JSON / JS 객체 리터럴 / `const firebaseConfig = {…};` 3형식.

## §4 레이아웃
탭바(각 탭은 이름만 · 오른쪽에 ＋추가 ⧉복제 ✕삭제 — 현재 탭 대상) / 탑바(＋노드 ✨AI노드 🔀정렬 [상태] 🔒 🌐 💬 📜 ⚙ 💾 📂) / 4000×4000 캔버스 팬·줌(0.15~3) / 우측 패널 480px.

## §5 기능
- 탭 추가·복제(딥카피+ID 재발급+엣지 리맵, 제목 `복사_원본`)·삭제(마지막 탭 불가).
- 노드: 클릭 펼침+선택(드래그 후 클릭 억제), 3px 드래그, 우클릭/0.5초 롱프레스 메뉴(10px 이동 시 취소, 발동 시 드래그 강제 해제).
  메뉴: 노드 편집 / 관계 추가 / 주인공 방문 / 현재 노드 추천 / 하위 노드 AI 추천 / 삭제(자식 처리 선택).
- 엣지: 부모=실선, 일반=점선, CJK 줄바꿈 라벨, 관계 추가=배너 → 대상 클릭, ESC 취소.
- 🔀 정렬: 부모-자식만 사용하는 **조직도(상위→하위 계층 트리)**. 자식 묶음의 폭을 재귀로 재고 부모를 그 가운데 놓아 가지가 겹치지 않는다. 같은 세대는 한 줄, 세대 간격 190px, 전체는 가로 중앙 정렬. 순환 참조는 끊어 안전하게 배치한다, 확인 모달 → 0.5s 애니 → 줌핏. 편집 모드 전용.
- 🌐 세계관 설정 + 참고 이미지 3장. 💬 멀티턴 대화(시스템에 설정+노드+관계 주입). 📜 사건(order 정렬, AI 생성 1개).
- 🧭 주인공 방문: 2~3문단, 타입별(방문/대화/획득/체험), 연결 노드 등장, 다시 추천/이미지 생성/사건 저장.
- ✨ AI 노드 생성: 프롬프트 → 로딩 오버레이 → 굵은 글씨+펄스 미리보기 → 우하단 패널(추가/다시 생성/닫기). 모든 주요 명사 노드화, 기존 노드 이름 매칭 연결.
- AI 추천 3종(노드/하위/관계): 카드 3개 + ↻.
- 편집 모드: 기본 보기 전용, 마스터 코드로 해제(현재는 Worker 검증), 모드 전환 시 노드 재렌더.
- 💾 `worldmind-export.json` 다운로드 / 📂 로드(확인 모달·개수 미리보기·덮어쓰기 경고 → 전체 교체 + Firebase 동기화 + 줌핏). **두 버튼은 ⚙ 설정 안 "데이터" 구역에 있다**(툴바에서 이동).

## §6 AI
- 텍스트: Anthropic Messages API, 모델 상수 `AI_MODEL='claude-opus-5'` 한 곳 관리. (현재 Worker 프록시 경유)

- §6-3 JSON 3단 방어: ①브래킷 카운팅 추출(문자열/이스케이프 인식) ②`JSON.parse` 직접 시도 우선 ③부분 복구(배열 내 개별 객체).
- §6-4 주인공 방문·사건 생성은 기존 노드 이름만 사용(시스템+유저 프롬프트 양쪽에 이름 목록 제약). 컨텍스트 빌더 재사용.

## 추가된 기능 (스펙 이후 요청)
- 관계(선/라벨) 클릭 시 상세 카드 토글, ESC/배경 클릭으로 닫기.
- 설정: 테마(다크/라이트 베이지), 연결선 색(단색/상위 노드 타입 색), 연결선 모양(곡선/직선). 즉시 미리보기·저장·취소 복귀.
- 노드 카드 2줄 구조(아이콘+타입 / 이름).
- 곡선 연결선: 다른 노드를 완만히 피하는 2차 베지어(`chooseCurve`).
- 📂 로드 버튼 상시 표시(보기 모드는 안내만).
- API 키·마스터 코드를 Cloudflare Worker로 이전(프록시). 사용자는 마스터 코드만 입력. Firebase 설정은 파일에 내장.
- 연결선을 노드 테두리에서 절단(반투명 카드 뒤 비침 제거), 겹친 노드 간 선 숨김.
- 펼친 설명 위 휠 = 내용 스크롤.
- ↩ 되돌리기/다시 실행 (Ctrl+Z / Ctrl+Shift+Z, 커밋 단위 30단계, Firebase에도 반영). **되돌리기는 현재 탭의 편집만 되감고 탭을 옮기지 않는다** — 탭 내용은 탭별 스택, 탭 추가·복제·삭제·가져오기는 별도 구조 스택이며 둘을 시간 역순으로 소비한다. 다른 탭의 실수는 그 탭으로 가서 되돌린다.
- 🔀 정렬은 누른 즉시 최종 좌표를 확정(되돌리기 1칸)하고 0.5초 애니메이션은 시각 효과로만 돈다. 계산 전에 펼친 노드를 모두 접어 접힌 크기로 배치한다.
- 다중 선택: 빈 캔버스 Ctrl(⌘)+드래그(마퀴 — 기존 선택에 합집합 누적)·Ctrl/Shift+클릭, 묶음 드래그 이동, Shift 드래그 시 이웃 중심선 스냅+가이드선. 팬은 빈 캔버스 드래그(수식키 없음)/Space+드래그/휠클릭/터치.
- 🏷 노드 타입: 상태 칩 옆 버튼 → 탭별 타입 추가(+)·이름 변경·순서(↑↓)·삭제(×). 사용 중인 타입을 지우면 그 노드는 최하위 타입으로 옮겨진다(노드는 사라지지 않음).
- 📥 노드 가져오기: 문서를 붙여넣거나 파일(.txt .md .csv .drawio .xml)을 끌어다 놓으면 AI가 노드·관계·필요한 새 타입을 만들어 **바로 추가**한다(미리보기 없음, Ctrl+Z 로 되돌림). drawio(mxGraph XML)는 도형·연결선을 코드로 정확히 파싱하고 AI는 타입만 배정한다(압축본은 DecompressionStream 으로 해제, 실패 시 안내). 이름이 겹치는 노드는 건너뛰고, **기존 노드 위치는 건드리지 않은 채 추가분만** 기존 내용 오른쪽 빈 공간에 배치한다. 입력은 앞 4만 자까지.
- 선택 영역 복사: **Ctrl+C** — 시스템 클립보드에 PNG(흰 배경 + 라이트 테마 색 고정. 화면이 다크 테마여도 문서·메신저에 붙였을 때 읽히도록) + 앱 내부 버퍼에 노드·관계. **Ctrl+V** 로 커서 위치에 붙여넣는다(다른 탭도 가능). 관계는 양 끝이 모두 선택에 포함된 것만 따라오고, 붙여넣은 노드는 새 id 를 받아 선택 상태가 된다. 클립보드 이미지가 막히면 PNG 파일로 저장한다.
- 🖼 노드 이미지: 상세 패널에서 파일 선택·드래그·붙여넣기로 추가. 올리기 전에 **긴 변 1600px JPEG 로 자동 축소**(보통 200~400KB)하고, 바이트는 Cloudflare R2 에 두고 노드에는 `{id,w,h,cap}` 참조만 남는다. 읽기는 공개, 업로드·삭제는 편집 토큰 필요. 순서 변경(↑)·설명·삭제 가능하고, ⚙ 설정의 "안 쓰는 이미지 정리"가 참조 없는 객체를 지운다.
- 📋 노드 목차: 🏷 왼쪽 버튼. 타입을 상위→하위 순서로 묶어 그 아래 노드를 나열한다. 여러 타입을 겸하면 주 타입에만 한 번 나오고, 같은 타입 안의 부모-자식은 들여쓴다. 항목을 한 번 누르면 그 노드를 선택하고 화면 중앙으로 옮기며, 0.4초 안에 같은 항목을 또 누르면 노드 상세까지 연다. 타입 이름을 누르면 그 묶음을 접는다(접은 상태는 이 브라우저에 남는다 — 아래 참조). 이름·설명·소속으로 걸러볼 수 있다.
- 노드 상세 ✏️ 편집 버튼은 패널 헤더 오른쪽 위(닫기 ✕ 왼쪽)에 있다. 노드 상세를 열고 노드를 하나 골랐을 때, 편집 모드에서만 보인다.
- 노드 설명은 보기 전용 방문자에게도 보인다. 보기 모드는 글(div), 편집 모드는 고칠 수 있는 칸(textarea)으로 갈린다.
- 설명·메모 칸을 손잡이로 늘린 높이는 이 브라우저에 기억한다(`wm_npsize`). 노드별이 아니라 브라우저 전체에 하나다.
- 목차에서 접어둔 타입 묶음도 이 브라우저에 기억한다(`wm_toc`). 자주 안 보는 묶음을 새로고침마다 다시 접지 않아도 된다.
- 메모 칸에는 머리글이 없다 — 무엇을 적는 칸인지는 placeholder 가 안내한다.
- 설정의 테마 선택은 2×2 격자다(좁은 화면에서는 1열). 카드마다 이름과 설명이 두 줄로 나뉘고, 설명은 …로 자르지 않고 접는다.
- 노드 카드에는 이미지 개수 배지(🖼 n)를 붙이지 않는다. 이미지는 노드 상세에서만 본다.
- 노드 상세의 이미지는 칸보다 크면 줄이고, 작으면 원래 크기 그대로 둔다(늘리지 않는다).
- 타입에 정해둔 기본 속성(`nodeTypes.fields`)은 저장·동기화에 함께 실린다. 🏷 타입 관리에서 "마법 → 코스트, 계열" 을 적으면 새로고침·다른 기기에서도 남는다.
- 🌐 참고 그림체 이미지는 일러스트 생성 시 실제로 AI 에 실려 나간다. 프롬프트는 실린 장수를 그대로 말하고, 선 굵기·채색·색감·명암을 따르되 그림 속 인물·사물은 옮겨 그리지 말라고 지시한다. 한 장도 못 받아오면 그림체 없이 그렸다고 알린다.
- 이미지를 넣는 길은 셋이다: 🖼 이미지 추가 버튼, Ctrl+V 붙여넣기, 끌어다 놓기.
  붙여넣기는 화면 어디에 포커스가 있어도 되고, 고른 노드에 들어간다.
  끌어놓기는 노드 상세 패널 위에만 받는다 — 열려 있는 노드로 들어간다. 캔버스의 노드 카드 위는 받지 않는다(옆 노드에 잘못 붙기 쉽다). 그래도 아무 데나 놓았을 때 브라우저가 그 파일로 이동하지는 않게 막는다.
  글을 붙여넣는 중(입력칸 + 클립보드에 글도 있음)에는 이미지 처리를 하지 않는다.
- 탭마다 주소가 있다: `…/loremap/#2` 는 두 번째 탭을 연다. 주소에는 순번을 쓰지만, 읽을 때는 탭 id(`#i1005`)와 탭 이름(`#첫 세계`)도 받는다. GitHub Pages 는 정적 호스팅이라 `/loremap/2` 같은 경로는 404 가 되어 쓸 수 없다. ⚠ 순번이라 앞의 탭을 지우면 예전 주소가 다른 탭을 가리킨다.
- 주소에 탭이 없으면 마지막으로 보던 탭(`wm_lasttab`)을 연다. 그것도 없으면 첫 탭.
- 설명·메모 자동 저장: 노드 상세의 설명과 메모는 편집 모드에서 바로 고칠 수 있다. 글자는 즉시 노드에 반영되고, 입력이 0.8초 멈추면 그때 `commit()` 이 한 번 돈다 — 저장·동기화·되돌리기가 모두 이 시점이다. 칸을 벗어나거나 창을 닫을 때도 즉시 밀어낸다(`flushPendingText`). 따라서 되돌리기 한 단계 = 끊김 없이 이어 친 한 덩어리.
- 🔍 노드 검색: **캔버스 왼쪽 위 버튼** 또는 **Ctrl+F**(누르면 그 자리에 검색창이 펼쳐진다). 이름·설명에서 찾아 금색으로 강조하고, ↑↓(또는 Enter)로 결과를 오가며 해당 노드를 화면 중앙에 놓는다(줌은 유지). 검색어를 바꾸고 Enter 하면 다시 찾고, ESC 로 닫으면 강조가 사라진다.
- 겹침 규칙: 보통 < 선택 < 펼침 < **마지막으로 건드린 카드**(항상 맨 위) 순으로 쌓인다. 펼침·선택·최상단 카드는 **불투명**하게 칠해 뒤 카드 글씨가 비치지 않는다. 카드 배경 블러(backdrop-filter)는 제거했다.
- 캔버스 단축키: **Tab** 커서 위치에 노드 추가(편집 모드 + 캔버스에 포커스가 있을 때만 가로챈다 — 툴바 Tab 순회를 살린다) · **Delete/Backspace** 선택한 노드/관계 삭제(확인 모달 필수, 다중 선택은 일괄) · **Alt**(단독 탭) 선택한 노드에서 관계 추가 시작(수식키 동반·드래그 중에는 발동하지 않음).
